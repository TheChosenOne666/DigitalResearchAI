> 版本：v1.0 ｜ 日期：2026-08-26

## 一、里程碑总览

```
M0 工程地基 → M1 认证与多租户 → M2 智搜核心管道 ★ → M3 知识库 RAG
                                                    ↓
              M7 上线强化 ← M6 管理端 ← M5 会员计费支付 ← M4 工作台与报告
```

**依赖关系**：M2 依赖 M1（登录态）；M2 先做联网+垂直两路（不依赖知识库基建），M3 完成后三路齐备；M5/M6 相互独立可交叉。

## 二、分里程碑计划

| 项 | 内容 |
| --- | --- |

| 项 | 内容 |
| --- | --- |
| 范围 | ① 意图分类（qwen-max + Zod，输出条件回填）；② 联网路：博查搜索 + 并发抓取（cheerio 静态 / Playwright 兜底）+ readability + 规则转 MD；③ 垂直路：世界银行 WDI API + 指标字典映射；④ RRF 融合 + gte-rerank 重排 + SimHash 去重；⑤ AI SDK 流式生成 + SSE 五阶段协议（stage/report_chunk/source/cond_fill/done/error）；⑥ 会话/报告/来源落库；⑦ 历史记录、中止/结束（AbortController 全链路贯穿） |

## 三、每个里程碑内的标准流程

```
后端接口开发 → 单元测试 → 前端开发 → 前后端联调（内置浏览器自测，截图/点击验证，
发现问题自行修复再验证，直到功能正常） → 文档同步（更新本目录对应文档）
```

- 每完成/改动一个功能同步更新 docs/ 下需求、进度与设计文档
- 一个里程碑完成后停下，等用户确认再进入下一个
- 测试重点：管道各阶段（fusion/rerank/转 MD）必须可单测（确定性代码）；支付幂等必须有重放测试

## 五、风险跟踪

| 风险 | 等级 | 缓解措施 | 关联里程碑 |
| --- | --- | --- | --- |
| LLM API 延迟/不稳定 | 高 | 多 Provider 热切换 + 熔断降级 + 缓存兜底 | M2 |
| 抓取被反爬 | 中 | Playwright 指纹伪装 + 代理池预留 + 单域名并发限制 | M2 |
| 大文档切片阻塞队列 | 中 | Worker 横向扩容 + 任务分片 | M3 |
| SSE 长连接占用 | 中 | 网关超时配置 + 心跳 + 连接数上限告警 | M2/M7 |
| 多租户越权 | 高 | ORM 强制注入 + 越权抛异常 + 审计 + 渗透测试 | M1/M7 |
| 计量不准 | 中 | Redis 原子计数 + 定时对账 + 明细可查 | M5 |
