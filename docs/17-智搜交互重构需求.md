# 17-智搜交互重构需求（选数据后分析）

> 状态：已确认（2026-09-09）
> 定位修正：产品核心价值是「帮用户找到对的数据」，用户主动挑选数据后进入分析，报告只是分析结果的载体。
> 确认记录：中途离开后允许继续用之前的检索结果（恢复窗口 30 分钟）；「送入工作台」场景本轮裁剪（数据形态不匹配，后续另立项）。

## 一、痛点

1. **用户无法参与数据选择**：当前智搜流程是「提问 → 检索 → 直接生成报告」一杆子到底。系统自动决定哪些来源进入报告，用户只能被动接受。若检索回来的数据不符合预期，30\~90 秒的报告生成时间全部浪费，用户只能换问法重试（再等一遍全流程）。
2. **勾选能力用途错位**：来源卡已支持勾选（现有 10 条候选逐条勾选），但勾选后唯一去向是「存入知识库」——与「用户选择数据做分析」的核心诉求不匹配。
3. **与工作台割裂**：用户想要对选中的数据做进一步分析时，需要手动另起工作台任务重新准备数据，勾选结果无法直接流转。

## 二、使用场景

### 场景 1：选数据再生成（智搜主流程重构）

用户输入「为什么2026年秋招就有公司招计算机28届实习转正？」→ 系统完成意图理解与检索后**停在数据选择步**，展示全部候选来源（含标题/摘要/类型）→ 用户勾选关心的数据条目（默认全部勾选，可取消）→ 点击「开始分析」→ 系统仅基于勾选的来源生成报告。未勾选的来源保留在来源卡列表中展示，但不进入报告正文引用。

### 场景 2：送入工作台分析（本轮裁剪，后续另立项）

~~用户在数据选择步勾选若干来源后送入工作台分析。~~ 落地评估发现智搜来源（文本）与工作台分析输入（结构化时序数据）形态不匹配，本轮不做，待后续定义参考资料/文本分析能力后另立项。当前勾选来源的去向：生成报告（主流程）+ 存入知识库（既有能力）。

### 场景 3：不选择直接生成（快捷路径保留）

用户不想逐步挑选时，可在数据选择步直接点「全部生成」，等同于全选后开始分析——保证原有「一键到底」体验不丢失。

## 三、验收标准

### 3.1 数据选择步（新中间态）

- [ ] 智搜流程变为「理解意图 → 检索 → **数据选择（等待用户）** → 生成报告」，检索完成后页面停留在数据选择态，不自动开始生成

- [ ] 数据选择态展示全部候选来源，每条可独立勾选/取消，默认全部勾选

- [ ] 提供「开始分析（基于勾选 N 条）」主操作，按钮显示当前勾选数量

- [ ] 至少勾选 1 条才可开始分析；全部取消时按钮置灰并提示

- [ ] 生成阶段的报告仅引用勾选的来源（未勾选来源不进生成上下文，不产生引文角标）

### 3.2 报告结果回归

- [ ] 勾选来源进入报告，引文角标按勾选集合重新连续编号

- [ ] 未勾选来源仍显示在来源卡面板（弱化态，标注「未选用」），可查看但不参与报告

- [ ] 生成完成后支持「重新选择数据」再次生成（换一批勾选重新出报告，不重复检索）

### 3.3 送入工作台分析

- [ ] 数据选择态提供「送入工作台分析」入口，将勾选来源作为数据输入创建分析任务

- [ ] 送入成功后给出跳转指引，可在工作台对应任务中看到这批数据

- [ ] 原有「存入知识库」勾选用途保留，不受影响

### 3.4 兼容与降级

- [ ] 历史记录回看旧报告不受影响

- [ ] 用户在选择步长时间停留后开始分析仍可用（检索结果不失效，超时窗口内可反复生成）

- [ ] 用户中途刷新/离开再回来，未完成的选择态有合理处理（重新检索或明确提示，不允许静默生成）

## 四、测试策略

| 模块          | 测什么                                                              |
| ----------- | ---------------------------------------------------------------- |
| 后端·新确认生成接口  | 正常路径（勾选子集→仅引用该子集）；边界（勾选空集拒绝、勾选编号越界、来源已过期/不存在）；权限（跨租户勾选非本人会话来源被拒） |
| 后端·送入工作台    | 勾选来源正确创建工作台数据/任务；重复送入幂等或明确报错                                     |
| 后端·SSE 协议调整 | 检索阶段完成后正确结束/挂起；新旧事件兼容                                            |
| 前端·数据选择态    | 勾选交互、按钮置灰、数量显示；重新选择再次生成；刷新恢复行为                                   |
| 前端·回归       | 未选用来源弱化展示；存入知识库功能不回归；历史记录/报告详情页不回归                               |
| 联调          | 端到端：提问 → 勾选子集 → 报告仅含勾选来源；送入工作台全链路                                |

## 五、暂不做（本轮范围外）

- 检索结果的数据字段级抽取（表格化数值展示）——来源卡粒度已够本轮使用

- 垂直路/本地路权重调整、embedding 404 修复（独立事项，另行处理）

- 多轮追问/会话式细化选数
