## 二、架构决策记录（ADR）

### ADR-1：模块化单体，不做微服务

- **决策**：NestJS 单应用 + Worker 进程分离（同一代码库两种启动模式：`NODE_ROLE=api` / `NODE_ROLE=worker`）
- **理由**：团队小、SaaS 早期，模块边界划清（每个业务域一个 module），保留后期拆分能力；微服务现阶段只有运维成本没有收益
- **边界约束**：module 之间只允许通过导出的 Service 接口调用，禁止跨模块直接访问他人 Repository

### ADR-2：多租户 = 行级隔离

- **决策**：所有业务表带 `tenant_id`，Prisma Client Extension 在 ORM 层强制注入（应用代码无法漏带）；Qdrant 用 payload 过滤实现同构隔离
- **理由**：库级/Schema 级隔离成本高且此阶段无必要；行级隔离 + ORM 层强制注入已足够安全
- **兜底**：跨租户访问在 Repository 层抛 `ForbiddenException`，配合审计日志

### ADR-3：重活全部异步

- **决策**：文档切片+向量化、报告导出、数据集导入、索引重建走 BullMQ 队列（对应管理端任务中心）
- **理由**：API 层只做编排和轻查询，智搜主链路保持低延迟；任务可重试、可监控、可终止（对应原型任务中心的状态/进度/重试/终止/错误日志）

### ADR-4：可插拔扩展点

- **决策**：
  - 数据源统一 `SearchConnector` 接口，新增数据源 = 新增一个实现类
  - LLM 统一 OpenAI 兼容协议 Provider，DashScope/DeepSeek 配置切换，不锁死厂商
- **理由**：SaaS 数据源和模型供给都会持续演化，扩展点必须开在架构层而不是散落在业务代码里

### ADR-5：SSE 单连接

- **决策**：智搜的 5 阶段进度 + 报告流式正文 + 来源卡推送走同一条 SSE 连接
- **理由**：减少连接管理复杂度；事件类型区分即可（`stage`/`report_chunk`/`source`/`done`/`error`）
- **约束**：网关需配置 SSE 透传（`X-Accel-Buffering: no`）；中止/结束用 AbortController 贯穿全链路（LLM 调用、抓取、上游 Promise 全部可取消）

## 六、智搜编排管道（核心链路）

```
用户问题 + 条件（国家/指标/年份）
        │
        ▼
① 意图分类（LLM Structured Output）
   输出 {intent, countries[], indicators[], yearFrom, yearTo}
   → 驱动条件栏回填 + 三路路由决策
        │
        ▼
② 三路并行（Promise.all + 超时熔断）
   ├─ 本地知识库：混合检索（Qdrant 向量 + PG 全文 → RRF）· 命中切片
   ├─ 联网检索：AnySearch 聚合搜索直连（POST /v1/search）→ 结构化结果（含正文 content，
   │            无需自建抓取/清洗；认证 Bearer 高配额，匿名按 IP 限流）
   └─ 垂直 API：世界银行 WDI → 标准化指标/字典映射
        │
        ▼
③ RRF 融合 · 打分排序
   score(d) = Σ 1/(60 + rank_i(d)) · 多路命中加权
        │
        ▼
④ Rerank 重排 · 质量过滤
   gte-rerank-v2 精排 → SimHash 去重 → 阈值截断 → TopK
        │
        ▼
⑤ Agent 流式生成
   干净上下文 → qwen-plus 流式生成 → SSE 推送 → 报告落库（含 {c:N} 引文映射）
```

**SSE 事件协议**：

| 事件类型 | 载荷 | 说明 |
| --- | --- | --- |
| `stage` | `{stage, label, progress}` | 5 阶段：意图解析/多源检索/数据标准化/智能分析/报告撰写 |
| `report_chunk` | `{text}` | 流式正文片段，含 `{c:N}` 引文标记 |
| `source` | `{sources[]}` | 来源卡（编号/名称/链接/简介/权威标识） |
| `cond_fill` | `{countries, indicator, yearFrom, yearTo}` | 条件栏 AI 回填 |
| `done` | `{reportId, usage}` | 完成，含用量计量 |
| `error` | `{code, message}` | 错误 |

## 七、数据架构

### 7.1 核心数据表（约 24 张，按域分组）

```
租户域    tenants, users, roles, user_roles
会员计费  member_plans, memberships, orders, payments, invoices, usage_counters
知识库    kb_libraries, kb_groups, kb_documents, kb_chunks, kb_configs
智搜域    search_sessions, search_reports, search_sources, search_histories
数据资源  indicators, dict_entries, datasets, import_reviews
系统域    tasks, audit_logs, notices, sys_configs
```

### 6.2 存储分工

| 数据 | 存储 | 说明 |
| --- | --- | --- |
| 业务数据（订单/会员/知识库元数据） | PostgreSQL | 唯一事实源 |
| 时序检索数据（WDI 类） | PostgreSQL | 国家×年份×指标宽表存储，工作台直查 |
| 文档切片向量 | Qdrant | collection 按知识库分（`kb_{libraryId}`），payload 带 tenant_id/groupId/docId |
| 全文索引 | PostgreSQL | pg_jieba 中文分词，与业务库同源 |
| 登录会话（`sess:{sid}` + `user:sids:{uid}`）| Redis | sessionId→用户上下文，TTL 滑动续期，支持踢下线 |
| 用量计量 | Redis（原子计数）→ 定时落 PG | 检索次数/token/存储配额 |
| 报告导出文件 | 对象存储（本地磁盘起步 → OSS） | 按租户目录隔离 |

### 7.3 检索数据流（知识库本地路）

```
文档上传 → 审核通过 → BullMQ 切片（按库级配置：分段方式/长度/重叠）
  → text-embedding-v3 向量化 → Qdrant upsert（payload: tenant/doc/group）
  → 学习完成（可被智搜命中）

智搜本地路查询：
  query → embedding → Qdrant 向量 TopN（租户过滤）
                            + PG 全文 TopN
                            → RRF 融合 → 返回命中切片
```

## 八、横切关注点

| 关注点 | 方案 |
| --- | --- |
| 认证 | Redis session 分布式会话（随机 sessionId + `sess:{sid}` 存用户上下文，TTL 7 天滑动续期，`user:sids:{uid}` 支持踢下线/在线设备管理）；手机验证码（阿里云短信 + Redis 60s 倒计时 + IP/手机号双维度限流防刷） |
| 授权 | RBAC 三角色（平台管理员/数据管理员/普通用户），NestJS 守卫 + 装饰器声明 |
| 多租户 | Prisma Client Extension 强制注入 tenant_id；Qdrant payload 过滤；文件按租户目录隔离 |
| 限流 | 网关层（IP/用户级）+ 应用层（Redis 令牌桶，智搜接口按会员等级差异化配额） |
| 幂等 | 支付回调：唯一约束 + 状态前置校验；任务提交：客户端 requestId 去重 |
| 审计 | 登录/导出/删除/管理操作统一审计拦截器落 `audit_logs` |
| 可观测 | Pino 结构化日志（requestId 贯穿）+ OTel 追踪（智搜管道每阶段 span）+ Prometheus 指标（队列深度/SSE 并发/LLM 延迟）+ Sentry 异常 |
| 配置 | 环境变量 + `.env.example`；LLM/搜索/数据源参数走管理端 sys_configs（热更新） |
| 备份 | PG 每日全量 + WAL 增量；Qdrant snapshot；恢复演练（对应管理端数据备份功能） |

## 十、架构风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| LLM API 延迟/不稳定 | 智搜主链路卡顿 | 多 Provider 热切换 + 超时熔断降级（缓存结果兜底） + 重试队列 |
| AnySearch 可用性/额度受限 | 联网路质量下降 | 超时熔断返回空 + SearchConnector 插槽可换其他供应商 |
| 大文档切片阻塞 | 队列积压 | Worker 独立进程横向扩容 + 切片任务分片 |
| SSE 长连接占用 | api 进程连接数 | 网关超时配置 + 心跳保活 + 连接数上限告警 |
| 多租户越权 | 数据安全事故 | ORM 层强制注入（无法漏带）+ 越权抛异常 + 审计 + 上线前渗透测试 |
| 计量不准 | 计费纠纷 | Redis 原子计数 + 定时对账落库 + 用量明细可查（账单页） |
