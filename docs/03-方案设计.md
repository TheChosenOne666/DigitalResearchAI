## 二、模块方案

### 2.1 智搜编排（核心模块）

**意图分类**
- qwen-max + Zod schema 结构化输出：`{intent, countries[], indicators[], yearFrom, yearTo, routeHints}`
- 输出直接驱动两件事：前端条件栏回填（SSE `cond_fill` 事件，回填后深色 has-val 状态，可手动微调）+ 三路路由决策
- 用户手动指定的条件优先于 AI 识别结果

**三路并行检索（SearchConnector 统一接口）**

| 路 | 实现 | 输出 |
| --- | --- | --- |
| 本地知识库 | Qdrant 向量 TopN（租户 payload 过滤）+ PG 全文 TopN → RRF 融合 | 命中切片（含来源文档/分组/命中分） |
| 联网 | AnySearch 聚合搜索直连（`POST /v1/search`，认证 Bearer / 匿名双模式）→ 结构化结果（title/url/snippet/content），正文已清洗无需自建抓取 | 来源卡（标题/链接/摘要）+ 正文 MD |
| 垂直 API | 世界银行 WDI（起步指标：GDP/CPI/人口/城镇化率等）；指标字典体系做 API 字段→标准指标映射 | 标准化时序数据集（国家×年份×指标） |

- 三路 `Promise.all` 并行，单路超时熔断（联网 15s / 垂直 10s / 本地 3s），一路失败不阻塞整体
- 检索模式由用户选择：混合（默认，本地优先）/ 联网 / 知识库——控制路由开闸

**融合与重排**
- RRF：`score(d) = Σ 1/(60 + rank_i(d))`；本地路命中加权 ×1.2（知识库优先原则）
- gte-rerank-v2 对 RRF TopN（约 30）精排 → SimHash 去重 → 相似度阈值截断 → TopK（默认 10，库级可配）
- 结果分级：引用级（进 Agent 上下文 + 来源卡）/ 参考级（仅来源卡展示）

**Agent 流式生成**
- qwen-plus + AI SDK `streamText`，Prompt 结构：系统指令（分析报告文体）+ 结构化数据表 + 引用级上下文（带编号 {c:1..N}）+ 用户问题
- 输出约定 `{c:N}` 引文标记 → 前端渲染角标 ↔ 右侧来源卡黄色高亮联动（原型 9.13/9.15 交互）
- 中止/结束：AbortController 贯穿 LLM 流 + 抓取 Promise，回到落地页并回填原问题
- 落库：会话、报告版本（含生成参数快照）、来源引用映射、用量计数

### 2.2 知识库 RAG

**四层数据模型**：库（kb_libraries）→ 分组（kb_groups）→ 文档（kb_documents）→ 切片（kb_chunks）

**文档状态机**（对齐原型 9.12）：

```
上传/存入 → 学习中断（可点击继续学习）→ 学习完成（参与智搜检索）
                  └→ 学习失败（可重新学习）
```

**库级向量化配置**（对齐原型 9.29 知识库配置页）：
- 基础信息：名称/可见性（私有/公共）/简介
- 向量化设置：分段方式（固定长度/智能）/ 分段长度 / 重叠长度 / 向量模型
- 检索参数：召回条数 TopK / 相似度阈值 / 混合检索权重

**混合检索**：Qdrant 向量 + PG 全文 → RRF（复用智搜管道 fusion 代码，权重按库配置）

**召回测试**（对齐原型）：输入测试问题 → 调检索层 → 返回命中文档片段 + 相似度分级（高/中/低），点击片段查看原文

**入库链路**（对齐原型 9.19/9.25/9.29）：
- 智搜报告「存入知识库」：存的是**用户勾选的来源**（每个来源独立一条文档），弹窗选库/分组/可见性/标签
- 工作台分析结果「存入知识库」：完整报告 + 勾选图表 + 数据分析表
- 统一流程：提交审核 → 管理端审核队列 → 通过 → BullMQ 自动切片学习（连续流程动画：生成 Word → 保存至知识库 → 文档切片）

### 2.3 数据工作台与报告

**数据工作台**
- 左侧多级筛选：国家/地区（实时计数）、时间（年份多选可折叠）、指标序列、数据来源（含知识库命中文档 + 上传文件）
- 右侧时序宽表：行=国家/地区，列=年份（2019–2025）；无数据 `..` 占位；行展开元数据详情；横纵滚动
- 上传数据补充：Excel/CSV（仅本地文件，对齐原型 9.15——数据库连接/API 导入已移除）→ 解析入库 → 即时并入筛选项与表格
- 底部操作：CSV/XML/EXCEL 下载、生成数据图表、生成分析结果、收藏到我的数据

**图表视图**
- 折线/柱状/面积/雷达 + 变体；坐标刻度分区、网格辅助线、数据标签开关、时间区间滑块
- PNG/SVG 导出（ECharts getDataURL）

**分析结果页**（对齐原型 9.27，独立页面非弹窗）
- 数据模型：报告摘要 / 5 张统计卡（样本覆盖/时间跨度/期末均值/区间变动/数据完整率）/ 逐经济体解读 / 分年度趋势 / 分组对比（发达/新兴/能源资源型）/ 指标口径 / 风险展望 / 方法说明
- LLM 按固定章节结构流式生成，≥3000 字
- 操作：下载文件（docx）/ 存入知识库

**报告导出**
- Word：docx 库，章节化排版 + 引文上标 `{c:N}` ↔ 文末来源表映射
- PPT：pptxgenjs，封面/摘要/图表页/来源页
- 图表：ECharts SSR（服务端 node canvas 渲染 PNG 嵌入文档）

### 2.4 会员计费

**套餐体系**（对齐原型 9.16）

| 等级 | 单月 | 连续包月 | 年付 | 权益 |
| --- | --- | --- | --- | --- |
| 免费体验 | — | — | — | 1 次智搜 |
| 专业版 | ¥59 | ¥49 | ¥499（划线¥708） | 无限智搜/导出/知识库 |
| 企业版 | ¥399 | ¥329 | ¥3999（划线¥4788） | 专业版 + 大容量 + 优先调度 |

**订单状态机**：

```
待支付 → 已支付 → 已完成
          └→ 退款中 → 已退款
         └→ 已关闭（超时未支付）
```

- 支付回调幂等：订单号唯一约束 + 状态前置校验（仅 待支付→已支付 可流转）
- 续费同周期在旧到期日上累加（对齐原型 `vipCalcExpire`）

**计量拦截**
- Redis 原子计数（检索次数/token/存储），定时落 `usage_counters`
- 拦截中间件：非会员体验用完 → 弹「开通会员」引导（未登录→登录并开通；已登录→去开通）；会员有效期内不限次
- 支付中心联动：会员身份/有效期/续费入口状态条（对齐原型 `vipPayStatus`）

### 2.5 认证与租户

- 登录双模式（对齐原型 9.4）：手机验证码（默认，+86，60s 倒计时重发；未注册自动创建账号）+ 账号密码
- 访客模式：未登录可浏览落地页，核心功能（检索/知识库）登录门禁（对齐原型 9.31）
- 会话：Redis session 分布式登录态——登录成功生成随机 sessionId（crypto 32 字节），`sess:{sid}` 存用户上下文（userId/tenantId/roles），TTL 7 天滑动续期；`user:sids:{uid}` 集合索引用户全部在线会话，支持踢下线/在线设备管理；Guard 每请求查 Redis 校验并续期，角色/禁用变更即时生效；多 API 实例共享同一 Redis，天然支持水平扩容
- RBAC 内置三角色：平台管理员/数据管理员/普通用户（管理端角色权限页可配）
- 审计埋点：登录/导出/删除/管理操作

## 三、接口设计规范

- RESTful，路径前缀 `/api/v1`；SSE 端点 `/api/v1/search/stream`
- 统一响应体：`{code, message, data}`；分页 `{list, total, page, pageSize}`
- 鉴权：`Authorization: Bearer <sessionId>`（Redis session 校验；SSE 用 `?sessionId=` query 兜底，因 EventSource 不支持自定义 header）
- DTO：Zod schema 单一事实源 → packages/shared 导出 TS 类型，前后端共用
- 错误码分段：1xxx 认证 / 2xxx 权限租户 / 3xxx 参数 / 4xxx 业务 / 5xxx 系统

**核心接口清单（用户端）**：

```
POST /auth/sms/send              发送验证码
POST /auth/sms/login             验证码登录（未注册自动创建）
POST /auth/login                 账密登录
POST /auth/logout                登出（销毁会话）

GET  /search/stream              智搜 SSE（问题+条件+模式+来源勾选）
GET  /search/histories            历史记录
GET  /search/reports/:id          报告详情（版本）
POST /search/reports/:id/save-kb  勾选来源存入知识库

GET/POST/PUT/DELETE /kb/libraries        知识库 CRUD（可见性/封面色）
GET/POST/PUT/DELETE /kb/:lib/groups      分组管理
POST /kb/:lib/documents                   文档上传（multipart）
GET  /kb/:lib/documents                  文档列表（分组/类型/状态筛选）
POST /kb/:lib/documents/:id/relearn      重新/继续学习
PUT  /kb/:lib/configs                    向量化/检索参数配置
POST /kb/:lib/recall-test                召回测试

POST /workspace/upload          Excel/CSV 上传补充
GET  /workspace/dataset         时序数据查询（国家/指标/年份筛选）
POST /workspace/analyze         生成分析结果（异步→报告页）
POST /report/export             Word/PPT 导出

GET  /vip/plans                 套餐列表
POST /vip/orders                 创建订单
GET  /billing/orders|payments    账单/流水
```

## 四、非功能需求

| 项 | 指标 |
| --- | --- |
| 智搜首字节延迟 | ≤ 3s（阶段事件先行，正文流式跟进） |
| 智搜全链路 P95 | ≤ 30s（含生成） |
| 工作台查询 P95 | ≤ 500ms |
| 可用性 | 99.9%（生产） |
| SSE 并发 | 单实例 1k 连接（压测验证） |
| 抓取成功率 | 静态 ≥ 85%，兜底后 ≥ 92% |
| 数据保留 | 报告永久（用户可删）；审计日志 1 年；备份 30 天滚动 |
