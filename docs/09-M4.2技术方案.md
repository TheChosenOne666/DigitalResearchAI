## 二、后端改动

### 2.1 新增 `workspace/upload-parser.ts`（纯函数，可单测）

```
parseTimeseries(buffer, mimeType, filename) → { rows: { name, values }[], years: string[] }
```

**约定上传文件为「宽表」格式**（与工作台「行=国家/地区、列=年份」一致）：

| 2020 | 2021 | 2022 |
| --- | --- | --- |
| 中国 | 5.2 | 8.1 |
| 美国 | -3.4 | 5.9 |

- 首列为实体名（国家/地区/城市/公司…），表头为年份（4 位数字），单元格为数值；
- `xlsx`：用 `xlsx` 包（已有依赖）读首个 sheet → `sheet_to_json({header:1, raw:false, defval:''})`；
- `csv`：`utf8` 解码 + 剥离 BOM；
- 空值 / `-` / `..` / `—` 记为 `null`（不生成年份键）；
- 表头非数字年份 → 抛业务异常（格式不符）；无数据行 → 抛业务异常。

### 2.2 `workspace.service.ts` 新增 `upload()`

调用 parser，产出 `UploadedDataset { rows, years, filename, size }`。

### 2.3 `workspace.controller.ts` 新增 `@Post('upload')`

`FileInterceptor('file', { limits: { fileSize: 20MB } })`，复用 M3 上传模式；只接受 `.xlsx/.xls/.csv`（`detectMimeType` 或扩展名白名单）。

### 2.4 依赖

无新增（`xlsx` 已在 M3 引入）。

## 三、前端改动（frontend/web）

### 3.1 `api/workspace.ts` 新增 `uploadDataset(file)`

FormData POST `/api/v1/workspace/upload`，复用 `request`（FormData 不设 Content-Type）。

### 3.2 `WorkspaceView.vue` 上传弹窗

- 「数据上传补充」按钮 → 弹窗（原型 8.5：dropzone + 文件列表 + 说明文案 + 完成）；
- 支持 `.xlsx/.xls/.csv`，多选/拖拽；「完成」逐文件上传；
- 返回解析行后：并入当前指标 `series`（同名实体合并填充、新实体追加），新增实体名加入左侧国家筛选列表，行展开元数据标注「本地文件 · {filename}」来源。

### 3.3 `WorkspaceView.vue` 图表视图

- 「生成数据图表」按钮 → 切换图表视图（原型 8.4 布局，含「返回工作台」）；
- 图表用 **ECharts**（新增依赖）渲染：折线/柱状/面积/雷达 + 数据标签开关 + 网格线开关 + 时间区间滑块；
- 图例展示选中国家；侧边「长周期走势研判」「智能图表推荐」卡片（原型一致）；
- 导出 PNG（canvas 转 base64 下载）/ SVG（序列化下载）。

### 3.4 `DatasetSeries` 增加可选 `source?: string`

标记本地文件来源，行展开元数据展示；WDI 行回退全局 `dataset.source`。

### 3.5 依赖变更（显式）

| 依赖 | 用途 |
| --- | --- |
| `echarts`（frontend/web） | 图表视图 4 图渲染 + 导出 |
