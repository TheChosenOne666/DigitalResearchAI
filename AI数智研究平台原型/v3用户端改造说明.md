## 三、AI智搜 · 一页对话（核心）

- 欢迎态：推荐问题（4 个快捷提问）、附件上传（Excel/CSV）、回车发送
- 提问后：用户气泡 → **5 阶段流程动画**（① 意图解析 ② 多源检索 ③ 数据标准化 ④ 智能分析 ⑤ 报告撰写，含"停止"按钮）
- 报告生成：标题/元信息/研究概述/KPI 卡/柱状图/数据表/引用上标/操作条（下载 Word·PDF·PPT、**存知识库**、重新生成、复制）/高级信息折叠区（数据源、命中数、耗时）
- 历史会话下拉：新建/复用历史问题

## 四、知识库 · 1 页 2 Tab（chatwiki 式）

- **顶部导航「知识库」无下拉框**，点击直达 `view-kb`
- **📄 文档 Tab**（chatwiki 知识库文档页同构）：
  - 左侧**知识分组栏**：全部文档 / 未分组 + 自定义分组（宏观经济 / 行业研究 / 企业分析 / 专题数据），可新建、重命名、删除、移动文档分组
  - 主区：状态统计（学习完成/待学习/学习失败/待审核）+ 列表/卡片切换 + 类型筛选 + 状态筛选 + 文档名搜索 + 「＋ 添加内容」
  - 表格列：文档名称（类型角标+标签）｜类型｜分组｜大小｜分段｜命中（合计/昨日/今日）｜状态｜操作（详情 / ⋯：编辑、移动分组、下载、归档、删除）
  - 状态流转：**待审核 → 待学习 → 学习完成**，学习完成后可被 AI 智搜的知识库优先检索命中；学习失败可重新学习
- **🏆 AI成果 Tab**：展示来源=AI智搜 的成果卡片（分类 + 复核状态筛选），统计成果总数/我的成果/待复核，支持查看、编辑、下载、发起复核（PRD U-10）
- **入库链路（U-11 检索成果入库）**：AI智搜报告操作条「**存入知识库**」→ 弹窗（文档名称 / 所属分类 / 标签 / 来源与生成信息）→ 确认 → 自动跳转知识库页，新条目以 **AI成果 / 待审核** 状态出现在文档列表顶部；管理端 A-16 审核通过后进入「待学习」

## 八、v3.3：一站式数据智能搜索（AI智搜）重构

### 8.1 登录后落地页（原首页 → 搜索落地页）
- 去掉旧版欢迎页/统计卡片/热门数据，#view-home 与 #view-smart-search 均替换为同一套 ss-shell 挂载点，登录后即见搜索落地页。

- 输入框下方 4 张圆角卡片（2×2 网格）快捷检索建议，点击即发起检索。
- 左上角历史侧栏伸缩 icon：可折叠/展开，存放历史记录（增删、清空、搜索过滤、点击重跑）。

### 8.2 检索结果页（流式纵向布局）
- AI 状态反馈条：解析问题意图 → 多源并行检索 → 数据标准化与清洗 → 智能分析与交叉验证 → 生成报告与可视化，5 阶段推进 + 完成状态 + 来源/耗时统计。

- 侧边来源锚点标注：右侧竖排锚点，点击平滑滚动到正文对应引文并高亮。
- 底部固定输入交互栏：`+` 上传 / 🧠 推理 / 🎤 语音 / 追问输入框 / 发送，可连续追问。
- 检索维度 Tab：全部 / 网页 / 数据 / 报告（含命中数），可切换。
- 结果内容：KPI 指标卡、可视化图表（折线/柱状/面积/雷达）、智能分析解读、趋势差异分析、智能图表推荐、结果数据表格（分页 + 排序）。
